# Examples

- `example_files/`: single-file programs, each a `NAME.soma` with, when
  it has them, its proofs in `NAME.proof` and its macros in `NAME.lang`.
  Run one with `soma run examples/example_files/hello.soma`; see
  `example_files/README.md` for what each shows.
- `example_projects/`: programs made of several files, in a folder of
  their own (see `example_projects/README.md`).
